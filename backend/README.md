# Backend

Carpeta reservada para el API (Node.js + Express + MySQL) descrita en la arquitectura del proyecto.
El prototipo actual funciona solo con el frontend: usuarios, catálogo, carrito y pedidos se
guardan en el `localStorage` del navegador. Cuando se construya el API, la URL se configura en
`Frontend/.env` con la variable `VITE_API_URL`.
